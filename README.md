# Omni API Tracker for SillyTavern

专门针对 SillyTavern（酒馆）打造的**全域无遗漏 API 调用审计与统计插件**。彻底打破市面上已有统计插件“只算正文生成、漏算记忆插件与预设工具”的通病。

---

## 🌟 核心痛点与破局

市面上的 Token / 费用统计插件大多依赖酒馆的“消息渲染事件”（`MESSAGE_RECEIVED`）：
* **只能统计正文**：只有聊天框里真正渲染出一条新对话时才会计数。
* **暗箱消耗全漏**：酒馆官方的 **Smart Context（智能上下文）**、**Memory（摘要/长程记忆）**、**Vectors（向量检索/知识库）** 以及第三方插件（如 **LittlewhiteBox 小白盒**、预设意图判定、脚本调用等）在后台发起的独立 API 消耗全被忽略。

**Omni API Tracker 的解决方案**：
从“业务事件层”降维到**“全局底层网络代理层（Global Fetch Interceptor）”**：
1. **100% 全量捕获**：只要走网络发往大模型或嵌入向量的请求，全部自动拦截审计。
2. **精准归因（Call Stack Trace）**：利用错误调用栈溯源，自动识别究竟是哪一个插件发起的请求（正文、记忆、小白盒、预设工具还是翻译）。
3. **无损流式旁路镜像（ReadableStream.tee()）**：对流式（SSE）打字机效果 0 延迟、0 阻塞，在后台旁路无感提取官方 `usage` 数据。

## 🚀 安装方法（极简，无后台配置）

本插件为**纯前端扩展（Client Extension）**，不需要配置任何 Node.js 服务端，不需要装任何 npm 依赖，不需要修改 `config.yaml`。

### 方式一：酒馆原生 UI 链接安装（推荐）
1. 打开酒馆，点击顶栏右上角的 **扩展插件（四个小方块图标）**。
2. 展开 **“安装扩展”**。
3. 在 Git 仓库链接输入框中粘贴：
   ```text
   https://github.com/ymf2317-tech/SillyTavern-OmniTracker
   ```
4. 点击 **保存（Save）/ 安装**。
5. 安装完成后，按 **F5** 刷新浏览器页面即可！

### 方式二：手动克隆 / 文件夹直投
直接进入你的酒馆扩展目录克隆：
```bash
cd SillyTavern/public/scripts/extensions/third-party/
git clone https://github.com/ymf2317-tech/SillyTavern-OmniTracker.git
```
刷新浏览器即可生效。

## 📊 功能特性

* **顶栏常驻微型状态灯**：显示今日总 Token 消耗，每次 API 调用时微闪呼吸灯。
* **独立审计看板**：
  * **用量概览**：今日消耗、本次会话消耗、历史累计，以及**分类占比进度条**（正文 vs 记忆 vs 预设工具 vs 向量检索）。
  * **实时调用流水日志**：精确到秒记录每次请求的发起插件、模型名称、输入/输出 Token、耗时毫秒。
  * **模型消耗分布**：按不同大模型（Claude、DeepSeek、Gemini 等）分类统计。
  * **数据维护**：支持导出 JSON 审计报告、重置会话、清空历史。

---

## 🛡️ 系统安全性说明

1. **绝对不碰原生核心文件**：所有代码封装在 `SillyTavern-OmniTracker` 独立目录中，不修改酒馆的任何原生文件。
2. **纯内存无感代理**：所有的代理仅存在于当前浏览器的运行内存中，所有网络请求原封不动放行。
3. **零残留彻底卸载**：如果不需要了，直接删除该文件夹（或在扩展面板卸载），酒馆立即 100% 恢复如初。
